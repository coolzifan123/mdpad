The first big update to MdPad, a free Typora-like Markdown editor for Windows.

**Download:** `MdPad_0.2.0_x64-setup.exe` below. Windows may say the app is from an unknown publisher, because it isn't code-signed yet; choose *More info → Run anyway*. From this version on, MdPad finds and installs new versions by itself (Help → Check for Updates).

### Writing
- Typora-style shortcuts: `Ctrl+1`–`6` headings, `Ctrl+B` / `I` / `K`, `Ctrl+T` table, `Ctrl+Shift+K` code block, `Ctrl+Shift+M` math, lists, quote, task list…
- `**`, `*`, `` ` ``, `##`, `[…](url)` appear around the formatting at the cursor
- `==highlight==`, emoji shortcodes (`:smile:`), footnotes, `[TOC]`, YAML front matter, Mermaid diagrams
- Find and replace with highlighted matches (`Ctrl+F`, `Ctrl+H`)
- Spell check, focus mode (`F8`), typewriter mode (`F9`), full screen (`F11`), zoom

### Files
- Menu bar, recent files, auto save, new window
- Sidebar with an outline and a folder's files; Quick Open (`Ctrl+P`)
- Export to HTML and PDF, print
- Saving keeps the parts of a file you didn't edit exactly as they were, and keeps line endings and encoding (UTF-8, GBK, UTF-16)
- Double-click a `.md` file to open it in MdPad; a file changed by another program is reloaded
- Custom CSS themes, and a Preferences window (`Ctrl+,`)
