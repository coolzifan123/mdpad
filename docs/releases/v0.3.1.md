A small update to MdPad. If you have 0.3.0 or 0.2.x, MdPad offers to install it for you (or use Help → Check for Updates).

### New
- **Paste a link over text:** select some words and paste a web address, and the words become a link to it.
- **Smart quotes** (Preferences, off by default): `"hi"` becomes “hi”, and `it's` becomes it’s.
- **Line numbers in code blocks** (Preferences, off by default).

### Better
- After clicking a result in **Search in Folder**, the find box has the focus, like `Ctrl+F`: `Enter` goes to the next match, and the formatting toolbar no longer pops up over the text.
- Typing in very large files does less work: the word count updates once you pause typing.

### Good to know
Typing in very large files is slower while a program reads the screen through Windows' accessibility interface, such as a screen reader or an AI "computer use" tool. Closing such a tool while you edit a big file brings the speed back.
