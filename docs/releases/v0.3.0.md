MdPad now lets you edit the Markdown itself, like Typora. If you have 0.2.x, MdPad offers to install this version for you (or use Help → Check for Updates).

### Edit the Markdown at the cursor
- Put the cursor in **bold** text and it shows as `**bold**`: the symbols in grey, the words still bold. Edit the symbols directly; when the cursor leaves, the text is read as Markdown again. This works for `*italic*`, `` `code` ``, `~~strike~~`, `==highlight==`, `[links](url)`, and a heading's `## ` (type another `#` to make it smaller, delete them to make it a paragraph).
- Pictures show as `![description](path)` with the picture under it, and formulas as `$E=mc^2$` with the drawn formula beside it.
- Just moving the cursor never changes your file. Turn it off with View → Markdown Symbols at Cursor.

### New
- **Search in a folder** (`Ctrl+Shift+F`): a Search panel in the sidebar lists the matching lines in every Markdown file of the folder. Click a line to open the file at that match.
- **Find options:** whole word (`Alt+W`) and regular expressions (`Alt+R`) next to match case (`Alt+C`). Regex replacements can use `$1`, `$2`…
- **Emoji picker:** type `:` and a few letters (`:smi`) to choose an emoji from a list.
- **Tables from a header line:** type `| Name | Price |` and press Enter.
- **Unsaved changes survive a crash:** if MdPad closes without saving (a crash, a power cut), the next start offers to restore your changes.
- Preferences: an option to type `*`, `_` and `` ` `` in pairs (off by default).

### Faster
- Typing in very large files is about four times faster.
