A small update to MdPad. If you have 0.2.0, MdPad offers to install it for you (or use Help → Check for Updates).

### New
- **Drag a Markdown file onto the window** to open it. Several files open in separate windows. Dropping a picture still puts it in the document.
- **Brackets and quotes in pairs:** typing `(` also adds `)`, typing `)` steps over it, and Backspace removes an empty pair. Turn it off in Preferences.
- **Edit → Copy as Markdown** and **Copy as HTML Code**, for the selection or the whole document.
- **Word count:** the status bar shows the words in the selection; click it (or Help → Word Count) for characters, paragraphs and reading time.
- **Tables:** Paragraph → Table Rows and Columns to insert or delete rows and columns and align them; `Ctrl+Enter` adds a row below.

### Fixed
- The outline no longer shows the `## ` symbols of the heading you are editing.
