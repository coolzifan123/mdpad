# Welcome to MdPad

MdPad is a **Typora-like** Markdown editor. What you see is what you get, and the file stays *plain Markdown*.

## Try it

- Type `# ` at the start of a line to make a heading
- Wrap text in `**` for **bold**, or in `` ` `` for `inline code`
- Press `Ctrl+/` to switch to source mode

### Tasks

- [x] Live preview editing

### A table

| Shortcut | Action |
| --- | --- |
| Ctrl+N | New file |
| Ctrl+O | Open file |
| Ctrl+S | Save |
| Ctrl+Shift+S | Save as |
| Ctrl+/ | Toggle source mode |
